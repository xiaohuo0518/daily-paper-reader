## 摘要
视觉-语言-动作（VLA）策略在机器人操作中表现出强大的性能，但仍易受运行时干扰的影响，这些干扰会破坏视觉观察、机器人状态和执行动作之间的时间对齐。我们提出了ActFovea，一个即插即用的保护框架，无需重新训练或修改底层VLA策略即可检测并缓解此类故障。ActFovea利用机器人运动学、本体感觉状态和近期动作来构建动作条件的中央凹区域，该区域保留接触相关区域和预测运动走廊，同时抑制与任务无关的视觉内容。它通过评估视觉运动和观察新鲜度是否与几何、本体感觉和动作转换保持一致来检测运行时风险。对于可恢复的干扰，ActFovea构建特定于干扰的候选观察，并在验证结果动作块后接受恢复。当过时或重放的观察使可靠恢复成为不可能时，它会调用有界的安全失败程序。在跨多个LIBERO套件的π_0闭环评估中，ActFovea在局部视觉覆盖下的成功率从49.3%提高到90.3%，缩小了与干净性能之间差距的93.7%。它还在动作漂移和视觉延迟下分别将成功率提高了7.0和9.8个百分点，同时保持了干净任务性能。在冻结观察重放下，ActFovea在所有试验中均触发及时的安全失败，且没有未受保护失败。这些结果表明，时空视觉-动作一致性为VLA策略的运行时保护提供了有效基础。

## Abstract
Vision-language-action (VLA) policies achieve strong performance in robotic manipulation but remain vulnerable to runtime disturbances that break the temporal alignment among visual observations, robot states, and executed actions. We introduce ActFovea, a plug-and-play safeguarding framework that detects and mitigates such failures without retraining or modifying the underlying VLA policy. ActFovea uses robot kinematics, proprioceptive states, and recent actions to construct action-conditioned foveated regions that retain contact-relevant areas and predicted motion corridors while suppressing task-irrelevant visual content. It detects runtime risks by evaluating whether visual motion and observation freshness remain consistent with geometric, proprioceptive, and action transitions. For recoverable disturbances, ActFovea constructs disturbance-specific candidate observations and accepts a recovery only after verifying the resulting action chunk. When stale or replayed observations make reliable recovery impossible, it invokes a bounded safe-failure procedure. In closed-loop evaluations of $π_0$ across multiple LIBERO suites, ActFovea increases success under localized visual overlays from 49.3\% to 90.3\%, closing 93.7\% of the gap to clean performance. It further improves success under action drift and visual delay by 7.0 and 9.8 percentage points, respectively, while preserving clean-task performance. Under frozen-observation replay, ActFovea triggers timely safe failure in all trials, with no unprotected failures. These results demonstrate that spatiotemporal visual-action consistency provides an effective basis for runtime safeguarding of VLA policies.

- **核心问题**：动作块预测使可靠控制高度依赖于视觉观察、机器人本体感觉（proprioception）和已执行动作之间的**持续对齐**。当这种对齐被破坏时，策略可能基于与当前物理状态不符的视觉证据做出错误决策。具体表现为四类运行时扰动：

  - **冻结观察重放（frozen-observation replay）**——反复供给同一陈旧帧，消除新鲜视觉锚定。
- **现有方案缺口**：已有安全防护方法（如控制屏障层、观察干预等）通常只针对单类扰动或施加预定义约束，无法在同一任务中应对多样化的扰动；过于保守的策略会抑制有效行为，而把一切异常都当作可恢复的又可能在失去感知根基后延长不安全控制。
- **核心论点**：运行时保护不仅要判断闭环是否已不一致，还须判断**是否存在合理恢复的余地**。区分这两者所需的可观察结构是**时空视觉-动作一致性**——视觉观察、本体感受转换和候选动作应共同描述机器人与环境的一个连贯物理演化过程。

## 2. 方法论：ActFovea

### 2.1 核心思想

ActFovea 是一个**即插即用、无需重训练**的运行时防护框架，作用于冻结VLA策略的观察-动作接口。其核心原则是：

- 利用机器人运动学、本体感受状态、视觉历史与动作历史构建**动作条件化的中央凹（foveated）区域**——保留接触相关区域与预测运动走廊，抑制任务无关背景内容；
- 通过评估**视觉运动与观察新鲜度是否与几何、本体感受和动作转换一致**来检测运行时风险；
- 对可恢复扰动，构造**扰动特定候选观察（threat-conditioned candidate observations）**，经**动作块验证**通过后才接受恢复；
- 当陈旧/重放观察使可靠恢复不可能时，调用**有界安全失败（bounded safe-failure）** 程序，产生保守运动抑制而非失控。

### 2.2 技术细节与流程

**（1）动作条件化中央凹与一致性监控**

- 中央凹定位跟随**预测交互**而非图像几何中心，随机器人运动学与动作历史动态更新。
- 对每个相机视角，通过正运动学估计投影接触中心与短时运动走廊，构造保持掩膜 \(M_v^t = \text{Dilate}(M_{c,t}^v \lor M_{\Gamma,t}^v, r_m)\)，其补集为可编辑背景。
- 滤波处理：\(\tilde{I}_v^t = (1-\alpha\bar{B}_v^t) \odot I_v^t + \alpha\bar{B}_v^t \odot E(I_v^t)\)，在保留接触邻域与运动走廊的同时去敏感化背景。
- 一致性评分综合几何一致性、动态一致性（预测与观察的图像位移方向/幅度）、时间证据（时间戳健康度、缺失局部运动、短历史匹配估计滞后、全局重放相似度）以及动作-本体感受一致性。
- 最终风险 \(R_t = \text{clip}(\beta \bar{r}_t + (1-\beta) r_t + p_t^{\text{cam}} + p_t^{\text{lag}} + p_t^{\text{cal}}, 0, 1)\)，其中包含相机可用性和标定一致性惩罚项。
- **确定性路由器**基于累积证据判断扰动类型与可恢复性状态，分为可恢复、边界、不可恢复三类。

**（2）一致性引导的恢复与动作验证**

- 候选观测库包含原始观测、中央凹观测、有限视觉延迟的时间稳定候选、以及空间覆盖修复候选。
- 对局部视觉覆盖，使用公式 \(\hat{X}_v^t = \text{clip}((P_v^t - \hat{\alpha}_v^t \hat{Q}_v^t)/(1-\hat{\alpha}_v^t), 0, 255)\) 重构干净区域，结合光流背景对齐、检测置信度与边界连续性门控。
- 每个候选经动作块验证器评分 \(V_k = \text{clip}(w^\top u_k + b_k, 0, 1)\)，考察首动作方向、末点方向、运动幅度、平滑度、水平与块漂移等指标。
- 选择规则固定，无参数优化；原始动作作为保守回退。

**（3）风险自适应执行与安全失败**

- 两阶段仲裁：一致性监控器决定执行/阻尼/缩短水平/保持；动作验证器选择正常执行、短水平执行、伺服恢复或安全失败。
- 最终决策：\(\hat{a}_{t,i}^{\text{mot}} = \lambda_t^{\text{mon}} \lambda_t^{\text{ver}} a_{t,i}^{\star,\text{mot}}\)，\(h_t = \min(h_t^{\text{mon}}, h_t^{\text{ver}})\)。
- 确认重放后进入不可恢复状态：在强重放证据或配置的陈旧连续帧后锁存保持，释放需足够新鲜证据；安全失败可前置一个裁剪的逆向动作，其余块填充保持。

### 2.3 与其他方法的本质区别

- 不是为某个特定扰动设计的专用防御器，而是**统一的运行时防护循环**：一个监控器、一个恢复路径、一个执行仲裁。
- 不对策略做任何梯度更新或参数修改，完全基于策略的观察-动作接口工作。
- 关键差异化能力在于**可恢复性判别**：区分有限延迟（可恢复）与持续重放（不可恢复），而非一刀切处理。

## 5. 主要结论与发现

1. **统一防护有效**：同一防护循环在空间（视觉覆盖）、时间（视觉延迟）与动作（漂移）三类扰动上均实现显著恢复：
   - 视觉覆盖：SR从49.3%提升至90.3%，恢复93.7%的性能损失；
   - 视觉延迟：SR从76.2%提升至86.0%（+9.8点，NRR 59.8%）；
   - 动作漂移：SR从83.1%提升至90.1%（+7.0点，NRR 73.1%）；
   - 干净场景下性能无损（93.8% vs 93.0%）。
2. **安全失败有效**：冻结观察重放下，全部2,000个episodes实现及时安全失败，无未保护失败；事后动作数减少99.23%，累积运动量减少99.87%。
3. **机制分工明确**：
   - 观察恢复（威胁类型识别、恢复候选库、候选扩展）是实现空间恢复的核心；
   - 动作验证是时间与动作侧恢复的主要保障；
   - 单独的技术（固定剪裁/短水平/时间戳暂停）无法跨扰动类型泛化，且各有显著副作用。
4. **时空视觉-动作一致性是有效的运行时防护基础**，可在训练-free条件下提供跨扰动的统一防护。

## 6. 优点

- **即插即用与训练-free**：无需重训练或修改策略，直接对接观察-动作接口，工程实用性强；
- **统一框架**：单套管线覆盖空间、时间、动作三类扰动，突破了以往“一扰动一防御”的碎片化局限；
- **可恢复性判别**：创新性地区分可恢复与不可恢复状态，避免过度保守或失去控制两种极端；
- **动作条件化中央凹**：不同于图像中心固定的foveation，跟随预测交互动态调整，保留下游任务真正需要的视觉证据；
- **实验严谨**：大规模闭环评估、多指标（SR/Gain/NRR）、多对比方法与系统消融，证据链完整；
- **安全失败有界**：明确了“零动作≠安全失败”的区别，保证了失败模式的可控性和可量化性。

## 7. 不足与局限

- **benchmark局限**：仅LIBERO仿真环境，无真实硬件验证；任务复杂度相对有限（桌面抓取/放置），未涉及移动操作、双臂协同等高维场景；
- **策略泛化性未知**：仅在π0上验证，框架对OpenVLA、RT-2、Octo等其他架构VLA的适配性未证；
- **扰动覆盖面有限**：未考虑组合扰动（如覆盖+延迟同时发生）、物理传感器攻击、对抗性扰动等更复杂威胁；
- **可恢复性边界依赖手工启发式**：威胁类型识别、候选生成、验证权重均为固定手工设计常数，未提供理论最优性或自动学习机制；对分布外扰动类型的适应性存疑；
- **算力/延迟评估缺失**：未报告推理时间开销、GPU型号与计算成本，难以评估实时机器人部署的可行性；多候选验证可能引入额外策略查询延迟；
- **安全失败不等同于形式化安全**：论文明确承认有界保守运动抑制不提供正式的碰撞避免保证；
- **潜在偏差**：扰动的代表性有限（如固定棋盘格覆盖、固定3帧延迟），可能与真实世界扰动分布存在差异。
