## 摘要
从人类视频中学习操作技能对于可扩展的机器人学习具有前景。然而，人类与机器人之间的本体差异使这一任务充满挑战。一种有前景的解决方案是学习与本体无关的、以对象为中心的可执行可供性。在本工作中，我们提出一个框架，利用第一人称视角人类视频、最先进的3D运动恢复结构和手部网格重建，来提取可执行可供性，如视觉可供性、抓取可供性和轨迹可供性，这些可供性明确编码了在哪里交互、如何抓取以及如何移动。我们构建了EgoAffordance，一个大规模数据集，包含204K个片段，其中包含560万个视觉可供性和1160万个抓取及轨迹可供性。在此基础上，我们引入VLAff，一个基于大型视觉-语言模型的统一基础模型，学习所有可执行可供性之间的跨模态相关性。给定视觉观察和指令，VLAff生成视觉可供性热图、抓取姿态和轨迹，并通过利用3D场景信息将其转换为可直接执行的动作。通过大量实验，我们证明VLAff不仅在视觉可供性预测上达到最先进性能，还能有效应用于真实机器人应用，如零样本操作和可供性引导的机器人学习。

## Abstract
Learning manipulation skills from human videos is promising for scalable robot learning. However, the embodiment mismatch between humans and robots makes this challenging. One promising solution is to learn object-centric actionable affordances that are embodiment-agnostic. In this work, we propose a framework that leverages egocentric human videos with state-of-the-art 3D Structure-from-Motion and hand mesh reconstruction to extract actionable affordances such as visual, grasp, and trajectory affordances that explicitly encode where to interact, how to grasp, and how to move. We construct EgoAffordance, a large-scale dataset comprising 204K episodes with 5.6M visual affordances and 11.6M grasp and trajectory affordances. Building on this, we introduce VLAff, a large vision-language model-based unified foundation model that learns cross-modal correlations across all actionable affordances. Given a visual observation and instruction, VLAff generates visual affordance heatmaps, grasp poses, and trajectories, which are then converted into directly executable actions by utilizing 3D scene information. Through extensive experiments, we demonstrate that VLAff not only achieves state-of-the-art performance on visual affordance prediction, but can also be effectively applied to real robot applications such as zero-shot manipulation and affordance-guided robot learning.

- 现有从人类视频学习可供性（affordance）的工作存在关键局限：仅聚焦单一模态（如仅视觉或仅接触点）、局限于2D图像空间、缺乏统一的模型来整合视觉、抓取和轨迹三种可供性。

**核心问题：**
1. 如何从人类视频中提取可执行的可供性数据？
2. 如何在一个统一模型中训练大规模可供性知识？
3. 如何将可供性知识应用于下游机器人操作任务？

**整体意义：** 论文提出用**对象中心的、与本体无关的可执行可供性**作为人类视频与机器人控制之间的桥梁，构建了大规模数据集和统一基础模型，实现从人类演示到机器人操作的完整链路。

## 2. 方法论

### 2.1 核心思想
将可供性分解为三个互补的、对象中心的表示，共同构成完整的操作理解：
- **视觉可供性（Visual Affordance）**：交互发生在何处（2D热图）
- **抓取可供性（Grasp Affordance）**：如何抓取（MANO手部参数）
- **轨迹可供性（Trajectory Affordance）**：如何移动（6D轨迹）

### 2.2 从第一人称视频中提取可供性（Affordance Extraction Pipeline）
1. **数据准备**：处理带语言描述和时间标注的自我中心视频，使用大VLM提取接触关键帧、动作标签、物体类别和交互手部信息。
2. **手物交互提取**：使用手物检测器获取边界框，生成物体掩码和2D手部关键点；通过指尖关键点与物体掩码的交集识别接触区域；提取MANO手部参数。
3. **视角去偏**：执行自我分割（ego segmentation）+ 修复（inpainting），消除第一人称视角的视觉偏差。
4. **3D场景重建（SfM）**：单目深度估计 + 相机姿态估计 + 3D手部轨迹跟踪，过滤动态区域确保稳健性。

### 2.3 VLAff模型架构
基于预训练视觉-语言模型（Qwen2.5-VL），引入三类专用token：

| Token类型 | 功能 | 输出 |
|-----------|------|------|
| `<SEG>` | 视觉可供性 | 通过分割解码器生成热图 Av |
| `<GRASP>` | 抓取姿态 | 96维MANO参数（腕部+15关节的6D旋转） |
| `<p0>~<pN-1>` | 轨迹token | 自回归生成离散化的6D位姿序列 |

**关键组件：**
- **VLM主干**：处理图像+语言指令，生成上下文嵌入
- **DINOv2视觉编码器**：弥补VLM在细粒度空间理解上的不足
- **视觉可供性解码器**：融合DINOv2特征与`<SEG>`嵌入，上采样生成热图
- **抓取解码器**：从`<GRASP>`嵌入解码MANO参数

### 2.4 训练损失
- **视觉可供性损失**：Soft Dice Loss（处理热图不平衡）
- **抓取损失**：Smooth L1 Loss
- **轨迹损失**：标准交叉熵损失（自回归语言建模）
- **总损失**：三个损失的加权和

### 2.5 轨迹采样策略
1. **上下文内轨迹引导（In-Context Trajectory Guidance）**：使用GPT等VLM作为高层规划器，提供3D方向向量 [dx, dy, dz]（每个分量∈{-1,0,1}），用于引导首个轨迹token的采样（正态分布）。
2. **基于采样的轨迹选择（Sampling-Based Trajectory Selection）**：通过top-p核采样生成K个候选轨迹，利用体素化碰撞检测 + 方向对齐的复合目标选择最优轨迹。

## 6. 主要结论与发现

1. **VLAff在视觉可供性预测上达到SOTA**：在所有指标上优于VRB、UAD、3DOI、LISA，证明统一多模态学习优于单一模态学习。
2. **零样本操作表现优异**：真实世界任务平均成功率68.0%，比现有最好方法VidBot（52.0%）高出16个百分点；仿真中83.0%与VidBot（85.0%）接近。
3. **视觉可供性是操作学习的关键**：移除视觉热图后，RL学习完全失败，表明该模态对成功操作至关重要。
4. **抓取姿态对操作学习贡献较小**：归因于人手与机器人夹爪的形态学差异。
5. **真实数据训练的优越性**：在真实世界杂乱场景中，从大规模真实自我中心视频学习的模型比在仿真中训练的模型更鲁棒。

## 7. 优点与亮点

1. **大规模高质量数据集**：EgoAffordance是首个同时包含视觉、抓取、轨迹三种可供性的数据集（204K片段，560万视觉热图，1160万抓取/轨迹），规模远超现有数据集。
2. **统一模型架构**：在单一VLM框架中联合建模三种可供性，利用跨模态相关性提升各模态性能，避免此前"各模态独立处理"的碎片化问题。
3. **对象中心表示**：通过将可供性转换为对象坐标系的相对表示，实现了与本体无关的迁移，有效解决embodiment gap。
4. **完整的自动化提取流程**：巧妙组合3D SfM、手部网格重建、分割、修复、跟踪等现有SOTA技术，构建可扩展的数据生成管线。
5. **可落的实机验证**：不仅做了离线评估，还在Fetch和PR2真实机器人上完成了零样本操作和RL微调实验。
6. **轨迹引导策略创新**：将VLM推理能力与基于采样的碰撞避免结合，提升3D轨迹的物理合理性。

## 8. 不足与局限

1. **轨迹物理合理性仍受限**：作者承认模型偶尔生成不符合物理约束的轨迹；虽然加入采样策略缓解，但根本问题未完全解决。
2. **缺乏3D场景感知**：当前模型主要从2D图像+语言推理轨迹，未来工作才考虑引入3D场景感知架构（如PointLLM）。
3. **算力信息缺失**：未报告训练基础设施相关信息，不利于可重复性和资源评估。
4. **对比公平性问题**：VidBot使用深度输入而VLAff仅用RGB，在仿真中的对比存在不公平因素；基线方法统一用GraspNet生成抓取，可能未达最优匹配。
5. **实验规模有限**：真实世界任务数量有限、可供性引导RL仅测试单一任务、缺乏跨任务泛化验证。
6. **抓取模态的局限**：实验本身表明人手抓取姿态对机器人夹爪的迁移价值有限，这一模态的有效性需进一步验证（如用于灵巧手）。
7. **统计严谨性不足**：未报告多次实验的方差、置信区间，以及失败案例的系统性分析。
8. **数据偏差风险**：数据主要来自自我中心视频，可能偏向特定场景/文化视角，物体类别分布也可能不均衡，存在泛化偏差风险。
