## 摘要
开集监督异常检测（OSAD）旨在利用有限的异常监督来识别未见过的异常。然而，现有的基于原型的方法通常通过单峰高斯先验对正常数据进行建模，未能捕捉固有的多模态性，导致决策边界模糊。为了解决这个问题，我们提出了混合原型流匹配（MPFM），一个学习从正常特征分布到结构化高斯混合原型空间的连续变换的框架。与依赖单一速度矢量的传统基于流的方法不同，MPFM 将速度场显式建模为高斯混合先验，其中每个分量对应于一个不同的正常类别。这种设计促进了模态感知和语义一致的分布传输。此外，我们引入了互信息最大化正则化器（MIMR）以防止原型坍塌并最大化正常-异常的可分离性。大量实验表明，在单异常和多异常设置下，MPFM 在多个基准上均达到了最先进的性能。

## Abstract
Open-set supervised anomaly detection (OSAD) aims to identify unseen anomalies using limited anomalous supervision. However, existing prototype-based methods typically model normal data via a unimodal Gaussian prior, failing to capture inherent multi-modality and resulting in blurred decision boundaries. To address this, we propose Mixture Prototype Flow Matching (MPFM), a framework that learns a continuous transformation from normal feature distributions to a structured Gaussian mixture prototype space. Departing from traditional flow-based approaches that rely on a single velocity vector, MPFM explicitly models the velocity field as a Gaussian mixture prior where each component corresponds to a distinct normal class. This design facilitates mode-aware and semantically coherent distribution transport. Furthermore, we introduce a Mutual Information Maximization Regularizer (MIMR) to prevent prototype collapse and maximize normal-anomaly separability. Extensive experiments demonstrate that MPFM achieves state-of-the-art performance across diverse benchmarks under both single- and multi-anomaly settings.

开集监督异常检测（OSAD）旨在利用有限数量的已知异常样本，检测训练阶段完全未见的异常类型。现有基于原型的方法（如 DPDL）通常使用单峰高斯先验对正常数据分布建模，忽略了真实工业/医疗数据中正常样本固有的多模态性（例如同一正常类别下存在多个子模式）。这种简化会导致正常样本的决策边界模糊，将稀有的正常模式误判为异常（假阳性），并降低对未知异常的泛化能力。本研究提出混合原型流匹配（MPFM），通过将正常特征分布连续变换到结构化高斯混合原型空间，显式捕捉正常数据的多模态结构，从而获得更紧凑、更鲁棒的正常边界。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程（用文字说明即可）
**核心思想**：利用流匹配（Flow Matching）学习一个从正常特征分布到高斯混合模型（GMM）先验的连续变换。该先验的每个高斯分量对应一个语义不同的正常模式，速度场也被建模为高斯混合，从而实现模态感知的分布传输。同时引入互信息最大化正则化器（MIMR）防止原型坍塌并增强正常-异常的分离性。

**关键技术细节**：
- **特征提取**：使用 ResNet-18 等骨干网络将图像映射到 d 维特征空间，得到正常特征集 Fn_tr 和异常特征集 Fa_tr。
- **混合原型流学习（MPFL）**：定义目标高斯混合原型分布 p₁(ψ(z₀)) = Σₖ πₖ N(ψ(z₀); μₖ, s²I)。流函数 ψ 将正常特征映射到该混合分布。传统流匹配回归单一速度矢量，MPFM 将速度场 qθ(u|z_t) 显式建模为 GMM：qθ(u|z_t) = Σₖ πₖ(z_t;θ) N(u; μₖ(z_t;θ), s²I)。训练通过最小化负对数似然 L_flow^normal = -log qθ(u|z_t) 使得正常样本的速度场拟合该混合分布，对异常样本使用相反目标 L_flow^anomaly = log qθ(u|z_t) 将其推离正常原型。
- **初始化**：对正常特征执行 K-means++ 聚类（K=32）初始化 μₖ、πₖ 和共享方差 s²。
- **闭环反向采样**：利用线性高斯模型性质，推导出保持混合结构的闭环反向转移公式 qθ(z_{t-Δt}|z_t)，无需数值积分即可实现稳定采样。
