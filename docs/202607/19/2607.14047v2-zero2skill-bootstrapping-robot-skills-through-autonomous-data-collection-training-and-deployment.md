## 摘要
自主数据收集决定了操作策略学习所需的真实世界轨迹的体量和质量。现有方法通过自复位、VLM验证或语言引导校正来减少人力投入，但每当相同故障重复出现时，必须重新发布针对回合的修复，因此监督成本随会话长度增长，而非随不同问题的数量增长。我们提出Zero2Skill，一种人机共生代理系统，其中校正被保留并在多个轮次中重用。收集循环自主执行收集、验证和复位，仅在某个阶段耗尽了显式的重试预算时暂停并等待远程操作员。一个LLM解析器将每个自然语言表述映射到存储在“校正记忆”中的结构化调整，因此已处理的故障模式通常无需在相同条件下再次校正。在真实机器人桌面清理测试平台上，Zero2Skill在匹配遥操作回合成功率的同时，将人力工作时间减少到16%。语言校正提高了所有四种评估设置中验证器与人类的一致性，并将平均单次尝试成功率从12.5%提升至47.5%（臂选择：20.0%至50.0%）。在Zero2Skill数据上微调的策略以远低于收集人力成本的比例，达到了与遥操作训练策略相当的成功率。

## Abstract
Autonomous data collection governs the volume and quality of real-world trajectories for manipulation policy learning. Existing pipelines reduce human effort via self-resetting, VLM verification, or language-guided correction, yet episode-scoped fixes must be reissued whenever the same failure recurs, so oversight cost grows with session length rather than with the number of distinct problems. We present Zero2Skill, a human-robot symbiotic agentic system in which corrections are retained and reused across rounds. The collection loop collects, verifies, and resets autonomously, pausing for a remote operator only when a phase exhausts an explicit retry budget. An LLM parser maps each natural-language utterance to a structured adjustment stored in Corrective Memory, so addressed failure modes typically need not be corrected again under the same conditions. On a real-robot desktop-clearing testbed, Zero2Skill matches teleoperation episode success while reducing human working time to 16%. Language corrections improve verifier-human agreement in all four evaluated settings and raise average single-attempt success from 12.5% to 47.5% (arm-selection: 20.0% to 50.0%). Policies fine-tuned on Zero2Skill data match teleoperation-trained policy success at a fraction of collection human cost.

#### **1. 核心问题与整体含义 (研究动机和背景)**

- **研究动机**：机器人技能学习严重依赖高质量的演示数据。然而，大规模数据收集面临一个核心瓶颈：人工成本高昂。现有的解决方案可归为三类：
    - **全手动遥操作**：数据质量高，但操作员需全程投入，成本与数据量成正比。
    - **全自主收集**：效率高，但缺乏处理“长尾”物理失败（如感知漂移、物体位移、策略死锁）的能力，故障会在长时间运行中累积且无法诊断修复。
    - **交互式收集**（如语言引导校正）：虽有进展，但修正通常仅作用于当前轮次（episode）。因此，同一个失败模式（例如，错误的成功判定标准）会在不同的轮次中重复出现，迫使操作员反复进行相同的干预。这导致监督成本随会话的**时长**增长，而非随**不同问题的数量**增长。
- **核心问题**：如何打破这种“重复修正”的循环，使人工干预产生的价值能够被持久化复用，从而将监督成本从与轮次数相关转变为与不同问题数量相关。
- **整体含义**：论文认为，应构建一个人机共生的系统。在该系统中，操作员提供自然语言形式的修正知识，而系统将这些知识转化为可复用的规则并存储。随着知识的积累，系统自主性不断增强，人类注意力可以聚焦于新问题，从而实现“一劳永逸”式的修正。这为降低大规模、长时程机器人数据收集的人力成本提供了一条新路径。

#### **2. 方法论：核心思想、关键技术细节**

- **核心思想**：将数据收集循环形式化为一个**验证门控的决策过程**。系统在自主执行“收集-验证-复位”循环时，拥有一个明确的重试预算。当某个阶段在耗尽预算后仍反复失败时，系统暂停并请求人工干预。关键创新在于，通过一个**校正记忆（Corrective Memory）** 机制，将人工的自然语言修正保留下来，并在后续所有轮次中自动应用，从而避免同一问题的重复干预。这被作者称为“交互式自主（Interactive Autonomy）”。

- **关键技术细节**：
    - **1. 自主收集循环**:
        - **任务规划**：基于大语言模型（LLM）和视觉语言模型（VLM）的代理（Agent）接收任务指令（如“学习整理桌面”），生成包含收集和复位方案、判断标准（verification prompts）的完整计划。
        - **循环过程**：系统交替执行收集和复位两个阶段。每个阶段执行完毕后，使用VLM（文中为Seed1.8）基于图像进行验证。
        - **重试预算**：每个阶段默认有3次重试机会（`N=3`）。若验证通过，则继续；若3次均失败，则进入警报（Alert）状态，通知远程操作员。
        - **显式边界**：重试预算和验证标准共同构成了明确的自主运行和请求人工的边界，避免了系统的静默退化。特别地，验证复位阶段至关重要，因为复位失败（场景漂移）是“沉默的”，不检查则无法被立即发现。

    - **2. 语言干预与校正记忆**:
        - **语言通道**：操作员在Alert状态下通过自然语言描述观察到的问题。
        - **LLM解析器**：使用LLM（文中为DeepSeek-V3.2）解析操作员的语句，并结合当前状态和记忆，决定如何进行修正。修正分两种：
            - **持久性修正**：如“物品任何一部分在篮子里都算成功”，会被解析为规则，附加到相关的判断提示词（prompt）中，并写入Corrective Memory。这些修正会影响后续所有轮次。
            - **一次性修正**：如“这次稍微向左移一点”，仅应用于当前轮次，不持久化。
        - **Corrective Memory**：一个轻量级的结构化Markdown文件，存储所有持久性修正。每条记录包含：触发条件（trigger）、修正内容（correction）、作用域（scope）和原始语句（source）。在每轮开始时，系统会查询并应用匹配当前情况的规则。

    - **3. 轨迹标记与质量认证**:
        - **双重标记**：每个轨迹被标记为执行是否成功（执行标签）和任务是否成功（结果标签），以区分是工具问题还是策略问题。
        - **质量检查**：计算运动平滑度、图像清晰度等指标，对每个录制作出“好/一般/差”的评级，独立于任务成功与否，用于过滤低质量数据。
        - **离线重判**：由于每轮都保留了最终观察，当验证标准被修正后，可以离线对所有已收集的数据重新标记，确保整个数据集标签标准一致。

    - **4. 策略学习与数据飞轮**:
        - 经验证的成功轨迹被合并用于微调底层VLA策略（本文使用π₀.5）。数据质量继承了收集过程中所有持久性修正的成果。
        - 评估时，去掉所有Agent、VLM、Corrective Memory和人工干预，只测试策略本身。
        - 文中明确阐述了设计理念，即整个循环旨在形成一个自我强化的飞轮，但本文字实验仅评估了一个“收集-修正-微调-部署”的完整单轮循环。

#### **6. 论文的主要结论与发现**

- **人工成本显著降低**：Zero2Skill在匹配全遥操作100%回合成功率的前提下，将人工工作时间从30.0分钟减少到4.8分钟（仅为全遥操作的16%）。其TpHM（10.42）是全遥操作（1.67）的约6倍。
- **语言修正有效**：
    - **验证器侧**：通过自然语言修正判断标准，在所有四个评估场景中均提高了VLM准确率，最高提升100%。
    - **执行侧**：语言引导的执行修正（SAM提示、抓取深度、臂选择）将平均单次尝试成功率从基线（12.5%/20.0%）显著提升至47.5%/50.0%，证明了系统能够处理感知和动作层面的长尾错误。
    - **累积有效性**：在实时收集过程中，累积的修正确实能稳定甚至提升收集成功率，但也出现了一次无效修正的例子，表明修正的收益取决于是否匹配了真实的失败原因。
- **数据足以训练高性能策略**：基于Zero2Skill收集的数据微调的策略，其策略成功率（80%）完全匹配了基于全遥操作数据微调的策略（80%），并显著优于基于脚本收集数据微调的策略（55%）。这表明通过语言引导验证收集的自主数据，其质量与人工示范数据相当。

    - **单轮飞轮验证**：虽然提出了“数据飞轮”概念，但论文仅展示了完整的一轮“收集→训练→部署”循环，未展示多轮循环下，随着策略改进，系统自主性是否持续提升，人工成本是否持续下降，这是缺乏说服力的。

    - **硬件的特殊性**：所有实验在特定的双臂Piper平台上进行，方法的**多体/跨平台泛化性**未在实验中得到证明。
- **技术局限**：
    - **依赖云模型**：系统严重依赖Seed1.8和DeepSeek-V3.2这类大规模云端模型，这带来了API调用成本、延迟和依赖性的问题。
    - **修正的边界**：Corrective Memory依赖于LLM的解析能力，其所能处理的问题类型受限于LLM的理解范围和可调用的工具。对于非常微妙或物理上难以用语言描述的故障，可能难以处理。
    - **未提及长尾失败的所有类型**：系统主要处理了验证标准错误、抓取深度、臂选择等问题。对于其他如物体滑动、碰撞、动力学特性复杂等更广泛的失败模式，其处理能力有待验证。
