## 摘要
端到端的视觉运动策略几乎不提供人类理解或校正策略视觉注意力的机会。我们提出GuidedAttention，一种视觉运动模仿学习框架，引入可解释和可校正的视觉注意力作为显式的中间表示。从相机图像中预测任务相关的注意力关键点，并作为条件指导基于扩散的动作策略。用户可以在 rollout 初始化时检查并有选择地校正选定的关键点，之后校正后的注意力通过跟踪模块在执行过程中自动传播。在仿真和真实世界的实验表明，GuidedAttention 持续提升机器人操作性能，特别是在位置和外观分布外（OOD）条件下。https://mmurooka.github.io/guided-attention-project-page

## Abstract
End-to-end visuomotor policies provide little opportunity for humans to understand or correct the policy's visual attention. We propose GuidedAttention, a visuomotor imitation learning framework that introduces interpretable and correctable visual attention as an explicit intermediate representation. Task-relevant attention keypoints are predicted from camera images and condition a diffusion-based action policy. Users can inspect and optionally correct selected keypoints once at rollout initialization, after which the corrected attention is automatically propagated throughout execution by a tracking module. Experiments in simulation and the real world demonstrate that GuidedAttention consistently improves robot manipulation performance, particularly under positional and appearance out-of-distribution (OOD) conditions. https://mmurooka.github.io/guided-attention-project-page

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
- 提出 **GuidedAttention** 框架，将任务相关的**注意力关键点**（attention keypoints）作为感知与控制之间的显式中间表示。
- 关键点由视觉注意力编码器（AttnEnc）从多视图 RGB 图像中预测，并用于条件化基于扩散的动作策略（**DP-GA**）。
- 用户可在 rollout 开始前选择性覆盖（override）预测的关键点，覆盖后的关键点通过跟踪模块（Co-Tracker）自动传播到整个轨迹。

#### 关键技术细节
1. **视觉注意力编码器 (AttnEnc)**  
   - 基于 DETR 风格的 Transformer 架构，使用 ResNet-18 作为 backbone，输出预设数量 \(N_k\) 的 2D 关键点坐标 \(\mathbf{p}_i\) 和对应的特征向量 \(\mathbf{f}_i\)。  
   - 坐标预测通过线性层实现：\(\mathbf{p}_i = A\mathbf{f}_i + b\)，参数 \(A, b\) 共享。

2. **关键点覆盖机制**  
   - 当用户提供校正后的关键点 \(\mathbf{p}_i^{gt}\) 时，通过线性映射的伪逆将其转换回特征空间：\(\mathbf{z}_i = h^{-1}_\theta(\mathbf{p}_i^{gt})\)，替换预测特征。  
   - 为保证特征空间一致性，引入**特征对齐损失** \(L_{feat} = \frac{1}{N_k}\sum\|\mathbf{f}_i - h^{-1}_\theta(\mathbf{p}_i^{gt})\|_2^2\)。  
   - 训练时采用**随机特征路由**，每次随机选择使用预测路径或覆盖路径的特征来条件化扩散模型，使模型对两种输入形式兼容。

3. **动作生成**  
   - 注意力特征 \(\{\mathbf{z}_i\}\) 与本体感受特征拼接，输入 CNN 的 Denoising Diffusion Policy（U-Net 骨干），生成机器人动作序列。

4. **关键点标注与跟踪**  
   - 训练时：用户仅在演示的第一帧标注关键点，后续帧由 Co-Tracker 自动跟踪。静态关键点保持固定。  
   - 测试时：策略自主预测关键点；用户可选择在初始帧覆盖部分关键点，跟踪模块维持后续帧。

### 6. 论文的主要结论与发现

1. **DP-GA 在完全自主运行时优于 DP 和 ACT**：在 ID 条件下提升约 15 pp（百分点），在 OOD 条件下提升约 10 pp。  
2. **可选的注意力校正进一步显著提升 OOD 性能**：校正后比自主运行提升 15–30 pp，比 DP 基线提升 20–30 pp。  
3. **注意力监督和特征路由是关键组件**：去掉两者导致性能大幅下降（校正后分别下降约 59 pp 和 67 pp）。  
4. **对跟踪和标注噪声具有鲁棒性**：在中等噪声下仍保持优势；噪声较大时才显著下降。  
5. **少量关键点（2 个）即可实现高成功率**，且不需要所有相机都校正。  
6. **在真实世界**：DP-GA 在位置 OOD 下提升明显（+20–40 pp），在外观 OOD 下通过校正实现约 +80 pp 的恢复。

### 8. 不足与局限

- **关键点表示能力有限**：假设少数手动定义的关键点足以表征所有任务，复杂场景可能需要更丰富的表示（如语义锚点、密集热图）。
