## 摘要
我们提出了MuJoCoUni，这是一个面向在线机器人学习和批处理物理评估的下游MuJoCo发行版。除了上游mujoco.rollout已提供的开环批处理轨迹生成外，MuJoCoUni还提供了用于有状态环境执行的运行时原语。目标工作负载需要高吞吐量的并行执行，同时保留上游CPU MuJoCo在模型、传感器、接触和约束方面的语义。其核心对象BatchEnvPool是一个C++/pybind11执行器，拥有每个环境的mjModel副本、每线程的mjData工作线程以及一个内部线程池。它提供仅最终状态的短步进、稀疏重置、重置生命周期内的域随机化、不推进动力学的批处理传感器前向评估，以及批处理雅可比矩阵和高度场查询。该实现仅限于Python绑定层；MuJoCo的求解器、接触模型、积分器和核心源代码树保留上游语义。本报告描述了BatchEnvPool API、实现边界、与rollout的关系，以及随开源mujoco-uni包一起提供的验证和基准测试脚本，该包可通过\texttt{pip install mujoco-uni}安装。

## Abstract
We present MuJoCoUni, a downstream MuJoCo distribution for online robot learning and batched physics evaluation. Alongside the open-loop batched trajectory generation already provided by upstream mujoco.rollout, MuJoCoUni supplies runtime primitives for stateful environment execution. The target workloads need high-throughput parallel execution while retaining upstream CPU MuJoCo semantics for models, sensors, contact, and constraints. Its core object, BatchEnvPool, is a C++/pybind11 executor that owns per-environment mjModel copies, per-thread mjData workers, and an internal thread pool. It provides final-state-only short stepping, sparse reset, reset-lifecycle domain randomization, batched sensor forward evaluation without advancing dynamics, and batched Jacobian and height-field queries. The implementation is confined to the Python binding layer; MuJoCo's solver, contact model, integrator, and core source tree retain upstream semantics. This report describes the BatchEnvPool API, implementation boundary, relationship to rollout, and the validation and benchmark scripts shipped with the open-source mujoco-uni package, which is installed with \texttt{pip install mujoco-uni}.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 设计并实现 `BatchEnvPool` 对象，这是一个基于 C++/pybind11 的执行器，拥有每个环境的 `mjModel` 副本、每个线程的 `mjData` 工作线程和一个内部线程池。它提供一系列“原语”供用户调用，所有并行执行都在 Python 绑定层完成，不修改 MuJoCo 的求解器、接触模型、积分器或核心源代码树。

### 关键技术细节
- **环境池管理**：
  - 每个环境拥有独立的 `mjModel` 副本（Deep Copy），避免共享模型状态。
  - 通过线程池（thread pool）为每个环境分配独立线程，每个线程拥有自己的 `mjData` 工作区，实现真正的并行模拟。
  - 支持指定并行环境数量（`num_envs`）和线程数（`num_threads`），线程数可小于环境数，此时多个环境共享线程（通过内部调度）。
- **短步进（Short Stepping）**：
  - 提供 `step` 方法，仅将每个环境向前模拟指定步数（如1步），并返回最终状态（观测、奖励、终止标志等），不返回中间轨迹。
  - 与上游 `rollout` 的开环长轨迹生成不同，`step` 适用于强化学习中的交互式循环（act→step→observe）。
- **稀疏重置（Sparse Reset）**：
  - 支持仅重置部分环境（通过布尔掩码），避免重置所有环境带来的开销。
  - 重置可附带域随机化：允许在重置时随机化模型参数（如质量、摩擦系数、关节阻尼等），每个环境独立采样。
- **域随机化（Domain Randomization）**：
  - 提供 `sample_randomization` 方法，用户可指定随机化分布（如均匀分布、正态分布），在重置生命周期内应用。
- **批处理传感器前向评估**：
  - 支持 `sensor_forward` 方法，在不推进动力学的情况下批处理计算所有环境的传感器值（仅执行前向传递）。
- **批处理雅可比矩阵和高度场查询**：
  - 支持 `jacobian` 和 `height_field` 等批量查询，适用于基于梯度的控制或地形感知。
- **实现边界**：
  - 所有功能都封装在 Python 绑定层（`mujoco_uni` 包），通过 `pip install mujoco-uni` 安装，依赖上游 `mujoco` 库。
  - 不修改 MuJoCo 二进制文件或核心 C 代码，仅通过 `pybind11` 包装现有 API。
