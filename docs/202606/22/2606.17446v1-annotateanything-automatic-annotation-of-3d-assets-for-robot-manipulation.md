## 摘要
模拟环境使得可扩展的机器人数据收集成为可能，但原始3D资产仅提供几何信息，缺乏指定机器人应如何以及在何处行动的语义、交互和物理知识。在这项工作中，我们提出了AnnotateAnything，一个通用的自动标注框架，可将被动的3D资产转化为带有结构化、多样化和可执行操作标签的、可操作就绪的资产。AnnotateAnything围绕两个互补的流程构建。首先，一个统一的视觉-语言标注流程，利用视觉-语言推理推断对象语义、交互约束和3D基础线索，为识别有意义的交互区域提供人类先验指导。其次，一个完全自动且大规模并行的物理标注流程，通过候选生成、几何优化和轨迹生成，将这些先验信息锚定在每个资产的几何和物理约束中。该流程生成多样且可执行的动作标注，包括抓取姿态、灵巧接触、关节运动路径点、插入方向、悬挂可供性和导航目标。利用生成的标注，我们进一步构建了一个跨不同对象、任务和机器人形态的异步并行模拟数据收集系统。实验表明，与现有的标注和数据生成流程相比，AnnotateAnything在标注效率、数据收集效率和任务成功率方面表现更优，同时还支持下游任务，如可供性检测、机器人视觉问答和视觉指令微调。我们在项目页面上提供项目材料，并计划发布完整代码、标注和基准以促进未来研究。视频、代码、演示资产和标注在补充材料中提供。项目页面：https://tourmaline-caramel-169490.netlify.app。

## Abstract
Simulation enables scalable robot data collection, but raw 3D assets provide only geometry, lacking the semantic, interactive, and physical knowledge needed to specify where and how robots should act. In this work, we present AnnotateAnything, a general automatic annotation framework that converts passive 3D assets into manipulation-ready assets with structured, diverse, and executable manipulation labels. AnnotateAnything is built around two complementary pipelines. First, a unified visual-language annotation pipeline using vision-language reasoning to infer object semantics, interaction constraints, and 3D-grounded cues, providing human-prior guidance for identifying meaningful interaction regions. Second, a fully automatic and massively parallel physics annotation pipeline grounds these priors in each asset's geometry and physical constraints through candidate generation, geometry optimization and trajectory generation. This pipeline produces diverse and executable action annotations, including grasp poses, dexterous contacts, articulation waypoints, insertion directions, hanging affordances, and navigation targets. Using the generated annotations, we further build an asynchronous parallel simulation data-collection system across diverse objects, tasks, and robot embodiments. Experiments demonstrate that AnnotateAnything achieves superior annotation efficiency, data-collection efficiency, and task success rates over existing annotation and data-generation pipelines, while also supporting downstream tasks such as affordance detection, robotic VQA, and visual instruction finetuning. We provide project materials on the project page and plan to release the full code, annotations, and benchmark to facilitate future research. ## 1. 核心问题与整体含义（研究动机与背景）

- **研究动机**：训练通用机器人智能体需要大规模、多样化的机器人数据，覆盖不同物体、形态和任务。模拟环境提供了一种可扩展的替代方案，但原始3D资产通常只编码形状和外观，缺少机器人学习所需的语义、交互和物理知识（如在哪里抓取、哪些部分可动、如何关节运动、插入/悬挂是否可行）。因此，关键瓶颈不是获取更多资产，而是将被动3D几何自动转换为带有可操作机器人交互标注的可操作资产。
- **核心问题**：为原始3D资产生成操作标注面临四大挑战：
  - **C1（语义级）**：标注必须编码人类交互先验，使生成的轨迹自然、安全且可能成功。
  - **C2（物理锚定）**：抽象交互意图必须转化为每个资产可执行的具体标签。
  - **C3（多样性）**：标注应保留多种有效解决方案，而非坍缩为单一规范解。
  - **C4（规模）**：过程必须覆盖大量资产、类别和交互，同时保持几何精度和交互特异性，无需人工逐资产设计或任务特定工程。
- **整体含义**：现有方法要么依赖昂贵人工标注，要么使用强化学习但需要奖励工程和复杂训练。AnnotateAnything旨在提供一种通用的自动标注框架，将被动3D资产转化为可操作资产，包含结构化、多样化和可执行的标签，从而支撑可扩展的机器人数据收集。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 构建**两个互补管道**：
  1. **统一视觉-语言标注管道**：利用视觉-语言模型（VLM）推理对象语义、交互约束和3D基础线索，提供人类先验指导，识别有意义的交互区域。
  2. **完全自动且大规模并行的物理标注管道**：通过候选生成、几何优化和轨迹生成，将先验锚定在资产几何和物理约束中，产生多样且可执行的动作标注。

### 关键技术细节

#### （a）层次化视觉-语言标注管道（第3.1节）
- **层次化语言标注**：
  - 资产级：对每个对象生成三级描述（短语、功能句、部分感知段落），总结对象身份、可操作部件和可行交互。
  - 房间级：为整个场景生成布局摘要、家具-区域描述、密集场景上下文。
- **层次化视觉标注**：
  - 资产级：通过多视图RGB-D融合重建点云，利用VLM从FPS采样中选择语义关键点；使用Hunyuan3D风格的3D部分分解（P3-SAM、X-Part）获得部分掩码和3D锚点。
  - 房间级：从模拟LiDAR和射线投射构建多高度占用图，提取地平面和墙壁结构。
- **跨层次组合与一致性**：将每个隔离的对象实例独立标注后转换回全局坐标，关联语义、视觉和动作相关标注。

#### （b）基于物理的动作标注管道（第3.2节）
- **统一动作标注模式**：候选库组织为从视觉锚点到技能到候选动作的一对多映射。每个动作候选包括：技能类型、关联对象、锚点、功能可供性、目标、技能参数、轨迹、可行性元数据、多样性描述符。
- **通用物理动作生成流程**：
  1. **候选目标生成**：根据技能类型、语言和视觉线索定位兼容区域，通过最远点采样（FPS）具体化目标，并经过几何和形态约束过滤。
  2. **轨迹生成**：根据约束源（对象属性、对象轨迹、对象向量、场景轨迹）生成初始轨迹模板。
  3. **轨迹优化**：在任务、接触、几何、形态和平滑目标下优化动作参数和路径点序列。
  4. **物理验证**：在并行物理仿真中验证候选，包括浮动末端执行器（用于大多数对象中心技能）和全机械臂验证（用于强形态依赖技能），并进行扰动和重力鲁棒性测试。
  5. **物理感知增强**：通过局部扰动和对称感知增强扩展已验证候选，保持功能可供性。

- **支持的技能**：包括平行爪抓取、灵巧抓取、双臂抓取、双臂灵巧抓取、关节运动、插入、悬挂、可变形物体操作、导航/逼近目标等18种原子技能。

## 3. 实验设计

### 数据集/场景
- **资产池**：处理了来自9个来源家族的17,005个资产，涵盖刚性物体、关节物体、可变形/服装资产、房间级场景。
- **审核评估套件**：从大资产池中采样1,160个资产-技能对（覆盖9个技能家族，共3,698个有效对），用于质量、成功率等指标的计算。另有一个手动标注子集（360个样本）用于视觉-语言标注评估。
- **真实世界零样本迁移**：6个代表性任务（抓取、灵巧抓取、插入、开抽屉、关盖子、长时任务），每个20次试验。

### 对比方法
- **内部消融**：
  - 直接VLM：直接用VLM预测。
  - 仅可供性+启发式：使用视觉可供性锚点+简单几何启发式。
  - 无3D细化：去掉点云一致性和部分区域细化。
  - Ours完整版。
- **外部基线**（经过适配后评估）：
  - ManiTwin-适配、MOPS-可供性+启发式、RoboGen-适配、MolmoBot-适配、GenManip-适配。
- **基准指标**：物理通过率、资产就绪率、执行成功率、标注吞吐量（批/分钟）、数据成功率、轨迹收集效率（轨迹/小时）。

### 评估维度
- 视觉-语言标注质量：人类评分（0-100）在语义、3D接地、覆盖率、可操作性四个维度。
- 视觉标注质量：部分、可供性、关键点匹配分数（基于手动参考）。
- 动作标注质量：每技能的通过率/就绪率、执行成功率、人体评分。
- 增强展开收集：随机化场景下数据成功率和收集效率。
- 真实世界零样本迁移：成功率。

## 6. 主要结论与发现

- AnnotateAnything能够将被动3D资产高效转化为带有结构化语言、视觉和动作标注的可操作资产，在17005个资产上产生了超过1亿个物理验证的动作标注。
- 完整管道在视觉-语言标注质量（人类评分~90.9/100）、物理动作标注质量（宏观执行成功率91.9%、人类评分85.6/100）和展开收集效率（数据成功率86.0%、收集速率165轨迹/小时）上显著优于所有消融变体和外部适配基线。
- 物理验证是关键：无物理验证时执行成功率从91.9%降至63.2%，数据成功率从86.0%降至57.6%。
- 所生成的标注可直接用于下游任务，包括可供性检测、机器人VQA和3D VLM指令微调。
- 仅使用仿真展开训练的策略能够零样本迁移到真实世界任务，在6个任务上取得了12/20至18/20的成功率。

## 7. 优点

- **统一性与泛化性**：提出了一个通用的标注模式，可同时处理刚性、关节、可变形和场景级交互，覆盖多种技能和机器人形态。
- **大规模自动化**：完全自动的流程，无需人工逐资产设计，能够处理上万资产并产生密集的动作标注。
- **多样性保持**：通过候选库机制和物理感知增强，保留多种有效候选而非单一规范解，支持任务内的多样性。
- **先验与物理协同**：VLM引入人类交互理解（语义先验），物理管道确保几何和动力学可行性，二者互补提高了标注的实用性。
- **可重用性**：标注不仅用于数据收集，还可转化为可供性、VQA和指令微调等下游任务的监督信号。
- **充分的实验验证**：包含了系统消融、外部基线对比、人类评价和真实世界零样本迁移，论证了方法的有效性。

## 8. 不足与局限

- **依赖上游模型与视觉质量**：语言标注质量受限于VLM能力和多视图渲染质量；部分遮挡、反射或模糊几何可能导致不准确语义先验。
- **对刚性/关节物体效果较好，对高度可变形或小接触物体偏弱**：实验显示可变形物体技能通过率（30.1%）和就绪率（78.9%）明显低于刚性物体（抓取60.3%/96.4%）。
- **仿真依赖性强**：物理验证依赖仿真器的碰撞、关节和接触建模，仿真与真实之间的差距可能导致部分标注在实际中不成立。
- **计算成本较高**：需要大量GPU资源进行批量物理仿真，标注吞吐量虽然较高但仍受限于硬件，在小实验室部署可能有难度。
- **真实世界实验有限**：仅作为初步验证，且任务种类较少，未进行全面真实世界基准评估。
- **资产许可与可再现性问题**：依赖于外部资产库（ShapeNet、Objaverse等），论文明确声明不会重新分发原始网格，用户需自行下载，可能影响部分实验的可复现性。
- **未涵盖所有任务和形态**：虽覆盖多种技能，但未包含所有可能的操作族（如液体的倒、绳类操作等）。
