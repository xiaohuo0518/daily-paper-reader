## 摘要
使用人形机器人完成日常任务需要协调稳定行走与多功能操作。然而，现有的全身控制器仍面临重大挑战。仅通过命令采样（无动作捕捉数据）训练的方法常受稀疏奖励困扰，需要精心调整课程才能收敛。这对于上半身控制尤其成问题，产生的动作偏离人类统计特征，降低全身协调性。相反，模仿全身动作捕捉数据的方法则受数据集不平衡影响，因为许多行走轨迹对于稳定行走场景过于激进，需要大量数据过滤和增强。为解决这一问题，我们提出复合全身模仿（CWI）框架，该框架将动作捕捉数据的使用解耦为上半身操作和下半身行走。这种解耦使我们能够利用包含多样化操作参考的完整动作捕捉数据集，而稳定的、基于命令的下半身行走则由双重判别器引导，这些判别器通过对抗性运动先验（AMP）在精心挑选的专家级行走和蹲伏片段上训练。多评判器架构减少了行走、操作和运动风格目标之间的冲突，而教师-学生蒸馏阶段产生了仅以双手位姿和速度/高度命令为条件的全身策略。我们通过仿真实验和在全尺寸LimX Oli人形机器人上的实际部署评估了CWI。结果表明，CWI具有竞争力的行走-操作性能、稳健的全身协调性以及无需全身动作捕捉设备的实用遥操作。项目页面及补充材料见https://cwi-ral.github.io/CWI-RAL-Webpage。

## Abstract
Achieving everyday tasks with humanoid robots requires coordinating stable locomotion with versatile manipulation. However, existing whole-body controllers still face significant challenges. Methods trained solely via command sampling, without motion-capture (MoCap) data, often struggle with sparse rewards and require carefully tuned curricula to converge. This is especially problematic for upper-body control, where the resulting motions deviate from human-like statistics and degrade whole-body coordination. Conversely, approaches that imitate full-body MoCap data suffer from dataset imbalance, as many locomotion trajectories are overly aggressive for stable-locomotion scenarios, necessitating extensive data filtering and augmentation. To address this, we present Composite Whole-Body Imitation (CWI), a framework that decouples the use of MoCap data for upper-body manipulation and lower-body locomotion. This decoupling allows us to exploit the full MoCap dataset of diverse manipulation references, while stable, command-conditioned lower-body locomotion is guided by dual discriminators trained on curated expert-quality walking and squatting clips via an Adversarial Motion Prior (AMP). A multi-critic architecture reduces conflicts among locomotion, manipulation, and motion-style objectives, and a teacher--student distillation stage yields a whole-body policy conditioned only on bimanual hand poses and velocity/height commands. We evaluate CWI through simulation experiments and real-world deployment on a full-size LimX Oli humanoid. The results show competitive loco-manipulation performance, robust whole-body coordination, and practical teleoperation without full-body motion-capture equipment. A project page with supplementary material can be found at https://cwi-ral.github.io/CWI-RAL-Webpage.

## 1. 论文的核心问题与整体含义（研究动机和背景）

人形机器人要在日常环境中执行任务，必须协调好稳定行走（locomotion）与灵巧操作（manipulation），即实现全身行走-操作（Loco-manipulation）。然而，现有全身控制器面临两大挑战：

- **基于命令采样的方法（无动捕数据）**：如仅通过奖励塑造学习，容易因稀疏奖励而难以收敛，且上身动作偏离人类统计特征，导致全身协调差。
- **基于全身动捕（MoCap）数据模仿的方法**：虽然可生成自然动作，但数据集存在严重不平衡——下半身轨迹中大量激进行走样本与稳定行走场景不兼容，需要大量过滤和增强，浪费了宝贵的上半身数据。

**核心动机**：如何充分利用丰富的人类动捕数据（尤其是上半身灵巧操作数据），同时保证下半身行走的稳定性和命令顺应性，实现一套无需全身动捕设备即可遥操作的实用全身控制策略。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想：数据解耦 + 复合模仿学习

CWI（Composite Whole-Body Imitation）将动捕数据的使用按身体角色解耦：
- **上半身**：使用完整的 AMASS 数据集（未过滤），提供多样化、人类风格的上半身操作参考。
- **下半身**：仅使用一小批精心挑选的专家级行走和蹲伏片段（约每类10段），通过对抗性运动先验（AMP）学习稳定的、命令条件的行走风格。

### 关键技术细节

1. **数据解耦策略**：
   - 上半身数据集 Mu：全部 AMASS 轨迹，相对于机器人基座坐标系表示，去除根部运动，包含关节位置、关键点位置、姿态等。
   - 下半身数据集 Ml：约10段行走 + 10段蹲伏的高质量片段，用于训练两个独立的 AMP 判别器（行走和蹲伏）。
   - 命令接口：下半身命令为速度命令(v_xy, ω_z)和高度命令h（采样覆盖全范围）。上半身教师使用完整参考 mu，学生仅使用双手9D关键点特征（18维），便于 VR 遥操作。

2. **复合模仿学习目标**：
   - **双重判别器（Dual Discriminators）**：基于 AMP 为行走和蹲伏各训练一个判别器，根据当前速度命令自动切换（非零速度→行走判别器，零速度→蹲伏判别器）。判别器输入为下半身状态窗口（4帧），输出风格奖励。
   - **任务奖励**：分为三组：
     - 行走任务奖励（rloco）：跟踪速度/高度命令的指数型奖励。
     - 上半身跟踪奖励（rupper）：关节位置 + 三角关键点位置（keypoint-based pose）的指数型 L2 损失。
     - 风格奖励（rstyle）：来自活跃判别器。
   - **多评论家架构（Multi-Critic）**：为三组奖励（行走、上半身、风格）分别分配独立的 value function，计算各自 GAE 优势，归一化后加权求和，再用 PPO 优化。缓解目标冲突。

3. **教师-学生蒸馏**：
   - 教师策略训练：使用完整状态（包含 Mu 参考）和上述复合奖励。
   - 学生策略：仅使用 proprioceptive 观测 + 双手9D关键点命令 + 速度/高度命令。
   - 训练方式：RL（PPO）+ BC（动作模仿），BC项将学生动作向教师动作靠拢，逐步退火。解决从完整参考到稀疏手部命令的差距。

4. **最终部署策略**：输入为双手9D关键点（由 VR 手柄提供）和速度/高度命令，输出31个关节动作。

## 6. 论文的主要结论与发现

1. CWI 通过数据解耦和复合模仿学习，在全身行走-操作任务上取得优于现有方法（HOVER*, FALCON*, HOMIE*）的跟踪精度和行走稳定性。
2. 多评论家架构显著减少了行走、操作、风格三个目标间的干扰，训练收敛更快、最终性能更高。
3. 教师-学生蒸馏对于从稀疏手部命令学习上半身操作至关重要，没有蒸馏时末端执行器误差激增（42.9→173.2 mm）。
4. 双 AMP 判别器相比单判别器或完全移除 AMP，能更好保持行走风格自然性（DTW 降低）且不影响操作精度。
5. 利用完整 AMASS 上半身数据比随机采样提供更接近人类运动统计的上半身参考，同时提升了下半身的行走性能（因上半身扰动减少）。
6. 策略自动学会了全身协调（如伸手时腰俯仰自动变化），无需显式命令。

## 7. 优点

- **应用限制**：不适用于需要脚部或肘部做接触点的任务（如踩踏板、用肘开门），且缺乏底层接触力控制。
