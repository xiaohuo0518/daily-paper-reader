## 摘要
生成式动力学模型使得在具有挑战性的机器人系统中进行规划成为可能，但安全部署需要可靠地检测策略引起的分布外（OOD）转移。现有方法通常将学习到的动力学视为固定的，并附加事后支持代理。我们表明，当动力学对关键动作选择局部不敏感时，这些代理可能会失效：不支持的控制动作可能产生类似于演示转移的潜在预测，从而抑制OOD信号，尽管真实预测误差较大。为了解决这个问题，我们引入了支持条件控制灵敏度正则化，该正则化在高支持训练区域中促进学习到的动力学对控制输入变化的局部敏感响应。这保留了控制引起的变化，同时限制了由于弱经验支持导致的不稳定外推。在基于视觉的避障、操作和真实机器人导航中的实验表明，OOD检测和闭环规划的安全性得到了改善。

## Abstract
Generative dynamics models enable planning in challenging robotic systems, but safe deployment requires reliably detecting policy-induced out-of-distribution (OOD) transitions. Existing methods typically treat the learned dynamics as fixed and attach post hoc support surrogates. We show that these surrogates can fail when the dynamics are locally insensitive to critical action choices: unsupported control actions may produce latent predictions that resemble demonstrated transitions, suppressing OOD signals despite large true predictive errors. To address this, we introduce support-conditioned control-sensitivity regularization, which promotes sensitive local response to control input changes in learned dynamics in high-support training regions. This preserves control-induced variation while limiting unstable extrapolation due to weak empirical support. Experiments in vision-based obstacle avoidance, manipulation, and real-robot navigation show improved OOD detection and safer closed-loop planning.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：生成式动力学模型（如世界模型）在机器人规划中广泛应用，但部署时因策略变化导致状态‑动作分布偏移（out‑of‑distribution, OOD），模型预测可能不可靠。现有OOD检测方法通常将动力学模型视为固定，并在事后附加代理分数（如k近邻距离、流量匹配负对数密度、集成分歧）作为支持度量，通过保形校准设定阈值来拒绝OOD输入。
- **核心问题**：论文发现，当学习到的动力学对控制输入局部不敏感（control‑insensitive）时，这些事后代理可能失效。即：未演示的控制输入产生的潜变量预测与训练分布中的过渡看起来非常相似，从而抑制OOD信号，尽管真实预测误差很大。这种“控制不敏感性”在安全关键区域（如障碍物附近）尤为明显，因为失败样例被排除，导致控制多样性低，动力学难以识别控制依赖的过渡。
- **整体含义**：要提升OOD检测的可靠性，不能仅依赖事后代理，而应从动力学学习本身入手，通过正则化增强局部对控制输入的敏感响应，从而让未支持的过渡在潜空间中更易区分。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
提出**支持条件控制敏感性正则化（support‑conditioned control‑sensitivity regularization）**，在高支持训练区域（即训练数据密度高、k近邻距离小的样本）中，促进学习到的动力学模型对控制输入具有非平凡的雅可比范数，从而保持控制引起的潜变量变化，避免未演示控制导致过度相似的潜变量预测。

### 关键技术细节

1. **控制敏感性度量**  
   对每个潜状态‑控制对 \((z_t, u_t)\)，计算控制雅可比矩阵 \(J_u F_\theta(z_t, u_t)\) 的Frobenius范数 \(\|J_u F_\theta\|_F\)，它衡量局部响应的大小。

2. **支持条件目标区域**  
   利用训练样本的潜空间k近邻距离（kNN）作为支持代理，定期选取支持度最高的 \(\beta\) 比例样本（即kNN距离最小的样本）构成高支持集 \(\bar{\mathcal{D}}\)，仅在此集合上应用正则化，避免在低支持区域强制敏感性导致不稳定外推。

3. **正则化损失函数**  
   \[\mathcal{L}_{\text{reg}} = \mathbb{E}_{(o_t, u_t)\sim \bar{\mathcal{D}}, z_t\sim \phi_\theta(\cdot|o_t)}\left[ \left( g - \left\| \frac{\partial F_\theta(z_t, u_t)}{\partial u_t} \right\|_F^2 \right)_+ \right]\]
   其中 \(g>0\) 是敏感度下界，\((\cdot)_+=\max(\cdot,0)\)，仅惩罚低于\(g\)的范数。总损失：\(\mathcal{L} = \mathcal{L}_{\text{dyn}} + \lambda_{\text{reg}} \mathcal{L}_{\text{reg}}\)。

4. **高效计算**  
   使用Hutchinson恒等式，通过若干随机投影向量估计Frobenius范数，避免显式构建完整的雅可比矩阵。

5. **算法流程**（参见Algorithm 1）  
   - 前 \(N_{\text{start}}\) 步仅训练基本动力学损失 \(\mathcal{L}_{\text{dyn}}\)，稳定编码器表示；  
   - 之后定期更新高支持集 \(\bar{\mathcal{D}}\)（使用潜空间kNN），计算 \(\mathcal{L}_{\text{reg}}\) 并加入总体损失。

## 6. 主要结论与发现

1. **控制不敏感性是OOD检测失败的关键原因**：在训练数据控制多样性低的区域（如障碍物附近），动力学模型可能对控制输入响应弱，导致未演示控制产生类似演示的潜变量预测，欺骗OOD代理。  
2. **支持条件敏感性正则化有效提升OOD检测**：  
   - 正则化后的动力学在近障碍区域恢复更强的控制雅可比范数，潜空间中演示/未演示控制过渡的可分离性显著提高（图6）。  
   - 在各种OOD代理（kNN, FM, ENS）下，正则化模型普遍获得更高的安全过滤成功率、更低的OOD违规率。  
3. **流匹配（FM）作为OOD代理表现最佳**，而集成（ENS）在单步过滤中表现不佳（因成员共享偏置）；正则化可缓解ENS的不足。  
4. **在块拔出操作中**，正则化模型允许使用更宽松的校准阈值（α=0.05）达到与Vanilla模型更保守阈值（α=0.1）相当甚至更好的安全性，表明敏感性改善降低了对保守校准的依赖。  
5. **支持分数β需谨慎选择**：过大（如0.6）会包含低支持区域，导致重建质量下降和过滤性能回落；最佳β通常约为0.2‑0.3。
