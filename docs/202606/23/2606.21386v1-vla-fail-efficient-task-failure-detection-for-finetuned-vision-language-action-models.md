## 摘要
视觉-语言-动作模型（VLA）在众多机器人操作任务上达到了最先进的性能，但在分布外场景下仍可能出现不可预测的行为。因此，运行时失败检测对于VLA的安全实际部署至关重要。然而，现有的任务失败检测器需要计算昂贵的动作采样，基于限制其应用于VLA的架构假设，或者需要访问失败轨迹。我们提出了VLA-FAIL，一种轻量级且广泛适用的VLA失败检测框架，它结合了两个新颖的失败检测器，具有最小的开销，并且不需要失败数据。第一个是最后一层马氏距离（LLMD），通过测量最后一层特征中相对于训练数据的词元偏差来检测分布外状态。第二个是动作块一致性（ACC），利用由后退水平控制引起的时间重叠，在连续动作块变得不一致时检测失败。为了捕捉检测精度和检测延迟之间的权衡，我们引入了AUCPDT，一个与阈值无关的指标，它联合评估了精确率、召回率和检测时间。通过大量的真实世界和模拟实验，我们证明了LLMD和ACC捕获了互补的失败模式，它们的组合能够在各种任务中实现可靠且早期的失败检测，通常显著优于更昂贵的基线方法。

## Abstract
Vision-language-action models (VLAs) achieve state-of-the-art performance on many robotic manipulation tasks, yet they can still behave unpredictably in out-of-distribution scenarios. Runtime failure detection is therefore essential for the safe real-world deployment of VLAs. However, existing task failure detectors require computationally expensive action sampling, are based on architectural assumptions that limit their applicability to VLAs, or need access to failure rollouts. We propose VLA-FAIL, a lightweight and broadly applicable failure detection framework for VLAs that combines two novel failure detectors with minimal overhead, without requiring failure data. The first, last-layer Mahalanobis distance (LLMD), detects out-of-distribution states by measuring token-wise deviations in last-layer features relative to the training data. The second, action chunk consistency (ACC), exploits the temporal overlap induced by receding-horizon control and detects failures when consecutive action chunks become inconsistent. To capture the trade-off between detection accuracy and detection latency, we introduce AUCPDT, a threshold-independent metric that jointly evaluates precision, recall, and detection time. Through extensive real-world and simulation experiments, we demonstrate that LLMD and ACC capture complementary failure modes whose combination enables reliable and early failure detection across diverse tasks, frequently outperforming significantly more expensive baseline methods.

### 论文提出的方法论

VLA-FAIL的核心思想是通过两个互补的、轻量级的信号来检测故障：**内部特征偏移**和**动作计划不一致**。它将这两个信号的阈值化组合，以实现更鲁棒和早期的故障检测。

*   **Last-Layer Mahalanobis Distance (LLMD) - 最后一层马氏距离**：
    *   **目标**：检测由OOD状态引起的内部特征表示偏移。
    *   **关键细节**：
        1.  **固定先验噪声**：由于VLA使用流匹配（Flow Matching）生成动作，其特征会受到采样噪声的影响。为隔离观测的影响，LLMD使用**一个固定的、预先采样的随机噪声向量**来计算特征，消除因随机性带来的特征变化。
        2.  **逐词元（Token-wise）处理**：论文发现，模型内不同词元位置的特征分布不同。因此，对于每个词元位置，分别计算其在训练数据上的均值和协方差矩阵。
        3.  **距离计算**：对于新的观测，计算其每个词元特征向量与训练数据分布之间的马氏距离，并取**所有词元距离的最大值**作为LLMD分数。分数越高，表明越可能是OOD状态，从而越可能失败。
*   **Action Chunk Consistency (ACC) - 动作块一致性**：
    *   **目标**：检测由OOD状态或模型内部错误导致的、**不连贯的动作计划**。
    *   **关键细节**：
        1.  **利用后退水平控制**：在后退水平控制中，当前动作块未执行的尾部与下一动作块的头部在时间步上重叠。如果策略是可靠的，这些重叠部分应保持高度一致。
        2.  **速度归一化**：为了衡量一致性，ACC计算重叠部分在机器人各动作维度上的平均绝对误差，并用该维度的**平均速度进行归一化**。这样能避免低速精细运动中被误判为故障。
        3.  **时间平滑**：对原始ACC分数应用指数移动平均（EMA），避免单次不一致导致的误触发，重点关注**持续的不一致性**。
*   **VLA-FAIL组合**：
    *   **决策规则**：当LLMD或ACC中的任何一个超过其**校准阈值**时，即判定为任务失败。这两个检测器捕获了互补的失败模式：ACC能有效检测危险、剧烈的不一致动作，而LLMD则能在动作看似平滑时，更早地检测出OOD状态。
    *   **阈值校准**：阈值通过时间常数共形预测（Conformal Prediction）在**成功**的校准数据上进行设定，无需失败数据。

### 实验设计

    *   **对比方法**：

### 论文的主要结论与发现

1.  **VLA-FAIL性能优越**：`VLA-FAIL`的组合方法在大多数任务和模型上，都取得了与甚至优于计算成本高昂的基线方法（`ACE`, `Diff`, `STAC`）的性能。
2.  **互补性证明**：`LLMD`和`ACC`确实捕获了不同的失败模式。`ACC`在任务中更容易检测到剧烈、不连贯的动作失败；而`LLMD`则能更早地检测出由OOD状态导致的失败。两者组合后（`VLA-FAIL`）在跨任务上表现最鲁棒。
3.  **轻量级优势**：`VLA-FAIL`仅需要极少的计算开销（因为LLMD和ACC的计算仅依赖于单次前向传播和已生成的缓存动作），具备实时部署的能力，而基线方法由于计算过重无法实现实时运行。
4.  **AUCPDT指标有效性**：`AUCPDT`指标能有效区分具有相似检测率但不同检测延迟的方法，揭示了`LLMD`通常比`ACC`检测更早的优势。

### 优点

1.  **轻量级与实时性**：VLA-FAIL是唯一一个具备实时运行能力的故障检测框架，这对于闭环节点控制至关重要。
2.  **无需失败数据**：避免了昂贵且有风险的失败轨迹收集过程，仅依赖成功演示数据进行阈值校准。
3.  **广泛适用性**：不依赖于特定VLA架构假设，可以无缝集成到使用流匹配、扩散或离散动作的VLA中。
4.  **检测器互补性**：结合了特征层面和动作层面两个互补的故障信号，提高了检测的鲁棒性和早期性。
5.  **全新评估指标AUCPDT**：提出并验证了一个更有意义的联合评估指标，能更全面地评价故障检测器的实际应用价值。

### 不足与局限

1.  **对微调数据的依赖**：`LLMD`方法需要访问微调数据集来计算特征统计量。当数据无法获取或处理成本过高时，该方法将无法使用。
2.  **对动作重叠的依赖**：`ACC`方法依赖于后退水平控制中的动作重叠。在完全开环执行（无重叠）的场景下，ACC将无法工作。
3.  **无法检测“语义”故障**：如果失败是“一致的”且“平滑的”（例如，机器人自信地执行了与语言指令无关的任务，或停在原地不动作），`VLA-FAIL`可能无法检测到。论文指出，在这种情况下，需要结合基于语义的VLM方法。
4.  **实际部署中的“校准”挑战**：虽然阈值通过共形预测进行简单设置，但在实际部署中，如何为持续变化的、未知的分布外场景确定一个鲁棒的阈值，仍是一个实际挑战。
5.  **实验的限制**：虽然任务多样，但真实世界任务场景相对同质（均为桌面操作），仿真环境也基于LIBERO，未来可以进一步扩展到更复杂、更动态的环境（如移动操作、人机交互等）。
*   论文未详细说明其校准数据量（仅限于20个成功轨迹）对最终阈值稳定性的影响，少量校准数据可能因异常值导致阈值设定不佳。
