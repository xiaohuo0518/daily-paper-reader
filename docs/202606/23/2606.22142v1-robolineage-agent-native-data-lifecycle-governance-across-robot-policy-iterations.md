## 摘要
我们提出RoboLineage，一个用于机器人策略迭代的智能体原生数据生命周期治理系统。现代机器人策略通过重复的数据收集、审查、重新训练、评估和发布决策来改进，但连接这些步骤的证据往往分散在本地工具、脚本和专家记忆中。RoboLineage通过将回放、审查、数据集决策、训练运行、策略元数据、评估、部署建议和下一轮收集计划表示为类型化的谱系工件，使这一生命周期显式化。智能体解释具身回放证据，将接受的数据适配到现有训练栈，维护数据健康，并在显式的工件边界下总结跨迭代状态。在真实机器人操作流程中，RoboLineage使常规策略迭代更快、更可审计，同时保持下游策略性能。我们将RoboLineage作为轻量级生命周期层开源，适用于不同的机器人实体和训练家族。项目页面：https://robolineage.github.io/

## Abstract
We present RoboLineage, an agent-native data lifecycle governance system for robot policy iteration. Modern robot policies improve through repeated data collection, review, retraining, evaluation, and release decisions, but the evidence connecting these steps is often scattered across local tools, scripts, and expert memory. RoboLineage makes this lifecycle explicit by representing rollouts, reviews, dataset decisions, training runs, policy metadata, evaluations, deployment recommendations, and next-collection plans as typed lineage artifacts. Agents interpret embodied rollout evidence, adapt accepted data to existing training stacks, maintain data health, and summarize cross-iteration state under explicit artifact boundaries. In real-robot manipulation workflows, RoboLineage makes routine policy iteration faster and more auditable while maintaining downstream policy performance. We open source RoboLineage as a lightweight lifecycle layer for different robot embodiments and training families. Project page: https://robolineage.github.io/

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现代机器人策略迭代（策略学习）依赖重复的数据收集、审查、重新训练、评估和发布决策，但这些环节之间的证据（如回放视频、数据集变更原因、训练产出、评估结果等）往往分散在本地工具、脚本和专家记忆中，缺乏系统化的记录与可审计性。
- **后果**：当需要回溯“为何某个策略被采用”“某次数据集修改基于哪些证据”时，专家必须手动重建链条，过程脆弱且易错，阻碍策略迭代的可重复性与规模化。
- **目标**：将机器人策略迭代视为一个**数据生命周期治理问题**，提出一个轻量级、智能体原生（agent-native）的治理系统 RoboLineage，使整个数据生命周期显式化、可审计，并实现部分自动化。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将回放（rollout）、审查（review）、数据集决策、训练运行、策略元数据、评估、部署建议和下一轮收集计划等表示为**类型化的谱系工件（typed lineage artifacts）**，构建有向谱系图 `L_k = (V_k, E_k)`。
- 智能体（Agents）作为**工件产生者**，在生命周期的每个转换点读取当前谱系上下文，并写出经模式验证的工件，从而将专家式判断转化为可重复、可审计的生命周期状态。
- 五个设计原则：可追溯性、语义覆盖、智能体自主性与显式状态、可移植性、操作效率。

### 关键技术细节
- **生命周期定义**：一次迭代可形式化为 `(b, τ, c_k) → R_k → A_k → D_k → T_k → π_k → E_k → G_k`，其中 `b` 是机器人配置，`τ` 是任务合约，`c_k` 是收集过程，`R_k` 为回放，`A_k` 为审查与准入工件，`D_k` 为数据集，`T_k` 为训练运行，`π_k` 为策略候选，`E_k` 为评估，`G_k` 为部署或下一轮收集决策。
- **智能体模块**：
  - **机器人注册智能体**：将机器人环境标准化为机器人配置文件。
  - **任务配置智能体**：定义任务阶段、成功标准、风险事件、准入规则。
  - **在线视觉快照智能体（VSA）**：在收集期间对关键事件窗口进行稀疏语义锚点提取（相位、进度、风险等），不阻塞原始采集。
  - **回放后审查智能体**：通过证据包（终端状态、后终端上下文、时间上下文、操作员日志）进行异步、结构化的最终注解。
  - **数据治理智能体**：将回放射击到训练资格、审查优先级、失败池路由等分类。
  - **数据健康智能体**：总结数据集级别的覆盖度、不平衡、缺失证据等。
  - **框架发现与数据集适配智能体**：自动发现训练框架的数据合约，并将其与接受的回放适配。
  - **训练监视智能体**：记录训练日志、指标、警告、检查点。
  - **版本治理智能体**：冻结数据集锁，绑定策略元数据。
  - **策略评估与部署治理智能体**：评估策略并给出部署/保持/回滚/再收集建议。
  - **主智能体**：提供跨迭代的综合记忆与建议。
- **工作机制**：每个智能体输出模式验证的工件，工件之间通过谱系边（如 `observes`, `reviews`, `admits`, `trains` 等）连接，形成完整的审计轨迹。

## 3. 实验设计

### 使用的机器人平台与任务
- **机器人**：ARX（ACT-style action chunking）、Realman（Diffusion Policy）、GALBOT G1（VLA/LeRobot 风格）。
- **审查基准**：25个任务，共500次回放，涵盖桌面操作、容器插入、接触式关节运动、可变形物体、方向与工具、长序列多物体操作等。
- **策略质量评估**：8个任务（与闭环研究不同），每个任务100个候选回放，从中选择60个训练，60个测试。
- **努力度研究**：12个匹配的30回放/轮次，对比人工工作流与RoboLineage工作流。
- **闭环回溯研究**：两个任务（叠方块、开抽屉），每个任务3轮，每轮30个接受回放+30个诊断试验，最后独立60试次测试。

### 基准方法（对比）
- Direct video-to-VLM
- VLM + schema only
- VSA-only (no post-review)
- Post-review only (no VSA)
- No final observation / terminal focus
- No packetized review
- Phase heuristic（仅计数失败阶段）
- No memory（无谱系记忆）
- Random（随机收集）
- Human expert（人类专家）

### 主要评价指标
- **审查可靠性**：结果准确率、失败阶段准确率、准入准确率、漏入率（leakage，即应拒绝却被接受的比例）。
- **策略质量**：成功率（与人类专家工作流对比）。
- **努力度**：主动人力时间（分钟/轮次）。
- **闭环改进**：三轮后的最终成功率。

## 4. 资源与算力

- **文中未明确说明训练策略所需的GPU型号、数量及训练时长**。RoboLineage本身不参与策略训练，仅管理数据生命周期；训练由外部策略学习者（如ACT、Diffusion Policy、VLA）完成，作者未报告其训练资源。

## 5. 实验数量与充分性

- **闭环回溯**：2个任务 × 4种方法（随机、阶段启发式、无记忆、RoboLineage、人类专家） × 3个独立运行，共30个训练-评估循环。
- **充分性评价**：实验设计较全面，既有独立组件消融，也有端到端对比；任务覆盖多种操作类型；但任务数有限（25个审查任务，8个策略任务，2个闭环任务）。模型后端仅部分测试（3个模型）。公平性方面：方法对比时使用相同的回放池、任务合约、训练命令和评估协议；专家标注用于真值，且专家未参与系统设计。

## 6. 主要结论与发现

- **审查可靠性**：完整 RoboLineage 在结果准确率（96.0%）、失败阶段准确率（88.0%）、准入准确率（96.4%）上优于所有消融基线，并将漏入率降至2.1%，接近人类专家一致率（97.0%/91.0%/98.0%）。
- **策略质量**：在8个任务上，RoboLineage 选择的训练集达到平均92.7%成功率，人类专家为93.1%，差距在0.4个百分点内。
- **努力度缩减**：常规轮次中，人类主动时间从130分钟降至54分钟（2.4倍减少），其中审查和集成时间大幅缩减（90分钟降至14分钟）。
- **闭环回溯**：在叠方块和开抽屉任务中，RoboLineage 引导的回溯最终成功率（85.0%/83.3%）显著优于随机（52.2%/50.0%）、阶段启发式（55.6%/53.3%）和无记忆规划器（68.9%/65.6%），接近人类专家（88.3%/83.3%）。
- **关键机制**：成功源于将主导失败模式转移到数据收集方向，而非简单增加数据量。

## 7. 优点（方法或实验设计亮点）

- **全生命周期覆盖**：首次系统地将机器人策略迭代中的分散步骤统一为可审计的谱系图，赋予每个工件身份和关联。
- **智能体原生治理**：通过智能体将专家式语义判断转化为模式验证的工件，既自动化常规工作又保留人的决定权，且输出可追溯。
- **设计分离**：将语义审查与数据集准入分离（例如“需要审查”不等于“拒绝”），防止错误信号污染训练集。
- **轻量级可移植性**：基于 JSON/YAML 工件和内容哈希，易于集成到现有机器人学习栈，且支持多机器人多框架。
- **实验设计相对严谨**：包含详细消融、模型后端敏感性分析、与人类工作流公平对比、闭环研究重复多次；提供了开源的工件和评分脚本以促进复现。

## 8. 不足与局限

- **实验覆盖范围有限**：仅针对桌面或视觉引导的操作任务，未覆盖力触觉、音频、外部位姿传感器等模态；未涉及移动操作、变形物体、高精度装配等复杂场景。
- **视觉语言模型依赖**：主要评估使用单一模型（Claude Sonnet 4.6），虽然测试了另两个模型，但精度有所下降，且模型错误可能以低置信度违规进入训练集（虽然系统可以路由到审查）。
- **治理范围**：当前系统假设人工负责收集界面、评估协议和安全过程，未自动化这些之外的安全审查；仅适用于“常规、已配置”的操作循环。
- **未处理更丰富的收集模式**：如部署时监控、策略建议模式等未被正式支持。
- **单实验室验证**：所有实验在作者实验室环境进行，缺乏社区大规模部署验证；多机器人、多团队、联邦式治理尚未实现。
- **未报告训练算力**：策略训练本身的算力需求未提及，因此无法评估 RoboLineage 对总训练成本的影响。
- **长期记忆局限**：主智能体虽提供跨迭代记忆，但为简便文本摘要，尚未建立机器人长时知识库。
