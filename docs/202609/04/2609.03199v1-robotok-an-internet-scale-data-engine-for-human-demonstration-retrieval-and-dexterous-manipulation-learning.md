## 摘要
机器人学习日益依赖于广泛且多样化的演示，然而收集机器人数据仍然成本高昂，且难以覆盖现实世界任务的长尾分布。为解决这一瓶颈，我们提出了RoboTok，一个互联网规模的数据引擎，给定查询的人体操作视频，它能够从网络视频中检索与操作相关的演示，用于训练灵巧的机器人策略。具体而言，我们从以估计的演员中心参考系表达的三维手部轨迹中学习一个潜在运动空间。这种表示使得操作行为能够在相机视角、场景外观和演员遮挡变化之间进行比较，同时保持紧凑性，足以支持对互联网规模视频集合的高效搜索和持续索引。我们在检索基准和下游机器人策略性能上，将RoboTok与现有的机器人数据检索方法进行了评估。结果表明，RoboTok能够检索到更相关的操作演示，并提高下游任务成功率，确立了手部姿势轨迹感知检索作为一种途径，使网络视频成为机器人学习可扩展且持续增长的监督来源。

## Abstract
Robot learning increasingly depends on broad and diverse demonstrations, yet collecting robot data remains expensive and poorly suited to covering the long tail of real-world tasks. To address this bottleneck, we introduce RoboTok, an internet-scale data engine that, given a query human manipulation video, retrieves manipulation-relevant human demonstrations from web videos for training dexterous robot policies. Specifically, we learn a latent motion space from 3D hand trajectories expressed in estimated actor-centered reference frames. This representation enables manipulation behaviors to be compared across variations in camera viewpoint, scene appearance, and actor occlusions, while remaining compact enough for efficient search and continual indexing over internet-scale video collections. We evaluate RoboTok against existing robot-data retrieval approaches on retrieval benchmarks and downstream robot policy performance. Our results show that RoboTok retrieves more relevant manipulation demonstrations and improves downstream task success, establishing hand-pose trajectory-aware retrieval as a way to make web video a scalable and continuously growing source of supervision for robot learning.

### 1. 核心问题与研究动机
- 机器人学习依赖大规模、多样化的演示数据，但真实机器人数据采集**成本高、效率低**，难以覆盖现实世界任务的“长尾”分布。
- 现有机器人数据集（如 Open X-Embodiment、DROID、BridgeData V2）虽规模可观，但仍属**固定、费力的专建数据集**，扩展至新任务、新物体、新环境需要重复的数据采集。
- 互联网视频（如 Action100M、HowTo100M）天然包含海量、持续增长的人体操作行为，覆盖场景与动作多样性远超专建数据集，且与人形/拟人机器人的形态高度契合（人手与机械手同构），是极具潜力的示范来源。
- 但是，网络视频**无标注、视角任意、场景杂乱、遮挡频繁**；更重要的是，视觉或语义相似并不等于**操作行为相似**——同一场景可能做不同动作，不同场景可能做同一动作。因此，不能依赖现有基于视觉特征或语言描述的检索范式。
- **核心问题**：如何构建一个互联网规模的数据引擎，让用户提交一段“人类操作查询视频”，即可自动、高效地从海量未知标签的网络视频中检索出**操作行为最相近**的演示片段，用于机器人策略学习？

### 2. 方法论
> RoboTok 的思路可以概括为：**以以人为中心的 3D 手部轨迹为行为表征 → 以 DTW 为相似性真值 → 训练轻量编码器 → 在嵌入空间做近似最近邻检索**。

#### 2.1 核心思想与技术路线
1. **候选片段过滤**：从 Action100M 等大规模语料中自动筛选出 4–8 秒、相机近静态、手部可见且无过多手部重叠的片段，作为可索引的候选演示。
2. **3D 手部姿态提取与度量重建**：以 5 fps 用 WiLoR 估计 3D 手部关键点（21 关节/手）；由于 WiLoR 基于弱透视模型，使用 MoGe-2 估计度量深度，将手部姿态转换到**公制相机坐标系**；缺失姿态用 HaWoR 补全。
3. **自我中心（Egocentric）轨迹表征**——这是全文最关键的设计：
   - 原始轨迹位于相机坐标系，**受视角影响大，无法跨视频直接比动作**。
   - RoboTok 训练了一个轻量级“人体躯干坐标系估计器”，仅利用手腕轨迹即可预测静态躯干坐标系；即使人体躯干被遮挡（互联网视频常态），只要双手可见就能完成坐标转换。
   - 所有手部轨迹被变换到以演员躯干为参照的**以人为中心的规范坐标系**，从而实现对相机视角、场景外观、人体遮挡的**不变性**。
4. **DTW 运动相似性真值**：在规范坐标系下，用动态时间规整 (DTW) 对齐两条轨迹，计算归一化负对齐代价作为行为相似性的“伪真值”度量，用于监督嵌入学习。
5. **轻量轨迹编码器学习**：将轨迹映射到单位超球面嵌入空间，训练目标为同时优化：
   - **集合损失**：使锚点轨迹的 DTW top-K 邻居靠近锚点，边界负样本远离；
   - **排序损失**：使正样本的相对内部顺序匹配 DTW 诱导的排序。
   - Batch 由“锚点 + 两个相关正样本 + 一个边界负样本”的组结构构成，保证训练批内存在有意义的相似对。
6. **推理（两阶段）**：
   - 离线阶段：所有经过过滤索引的片段被编码一次，向量存入索引结构；
   - 在线阶段：给定查询视频，仅一次前向编码，再做余弦相似度近邻搜索；新视频只需一次前向即可增量入库，无需重训。

#### 2.2 关键公式（文字版）
- **DTW 代价**：序列间最优对齐路径（允许时间伸缩/压缩）上各手部姿态欧氏距离的累计和最小化。
- **轨迹相似度**：负的 DTW 代价除以序列平均长度做归一化。
- **理想检索**：直接按该相似度对全语料排序取 Top-K——代价过大，不实际。
- **近似方案**：学习嵌入函数 Γ，使得嵌入空间的内积排序尽量与 DTW 排序一致；检索退化为向量近邻搜索，可扩展至百万级语料。

### 6. 主要结论与发现
1. **以行为为中心的检索显著优于视觉/语义式检索**：在自有评测语料（k=20）上，RoboTok 的 mAP@20 = 0.353，STRAP 仅 0.007，Flow/HAND 接近随机；Recall@20 达 0.996，几乎每个查询都可在 top-20 内命中最相近的 DTW 邻居。
2. **表征跨域泛化能力强**：在 AssemblyHands（真实 3D 标注、跨域语料）上依然全部指标领先（mAP@5 = 0.261 vs STRAP 0.133），证明自监督学到的运动空间并不依赖于自建语料。
3. **优化的局部邻居结构自动扩展为全局有序结构**：虽然训练仅针对 k=20 优化，但在 Recall@k、DTW cost@k、CKNNA@k 等更大 k 值上持续领先，说明嵌入空间全局组织良好。
4. **检索质量可转化为下游策略收益**：在原始 VTDexManip 基准上，RoboTok 取回演示引导的 PPO 在 6 个任务里 5 个超越 VT-JointPretrain；在移除手势限制和稠密奖励的更难任务中，RoboTok 引导的策略成功率分别超过次优方法 17.8%（瓶盖）、38.0%（水龙头）、59.8%（杠杆），学习速度也更快。
5. **Web 视频作为数据源的可行性**：实验从整体上证明，方法可提供一种“先检索后学习”的范式，支持持续索引和跨任务扩展。

### 7. 优点与亮点
- **视角/外观不变的运动表征**：以躯干为参考系而非相机系，是在“行为可比性”上的突破性设计；仅凭手部轨迹估算躯干坐标，能应对演员大部分躯干被遮挡的挑战，实际部署价值高。
- **用运动而非语言/视觉定义“相似”**：直接以“手的移动方式”为检索语义，更加契合具身操作的本质，且不需要任何人工标注或自然语言描述。
- **轻量编码器 + 向量检索**：避免了互联网级别的全量 DTW 计算；数据库以分布式向量索引承载，支持新视频“一条前向即可入库”的持续扩展，架构上满足互联网规模需求。
- **锚点 + 边界负样本的批构建设计**：针对轨迹数据高度重复的困难挑出了具有“只比相关集合差一点点”的边界负样本，有效提升检索模型在相关阈值附近的分辨力。
- **实验控制变量严谨**：全程不使用机器人动作或动作标签，下游只通过“最大奖励跟踪演示状态”这一途径引入检索结果，使性能差异能归因于检索质量本身。
- 表格对比清晰地把 “GT 上界”“随机基线”“其他做法”分开，便于读者定位方法效果位置。

### 8. 不足与局限性
- **依赖多个手部感知模型的级联误差**：WiLoR 手部检测 → MoGe-2 尺度恢复 → HaWoR 补全 → 躯干估计，每个环节在任意网络视频上都有失败风险；文中未量化各环节误差传播对检索性能的影响。
- **伪真值的循环问题**：训练与评测标准均基于 DTW，尽管 DTW 本身是经典算法，它仍无法完全代表“操作行为是否相同”的人类认知，尤其在手势路径相近但目的不同的场景（如写字 vs. 敲击）。
- **静态相机限制**：目前仅适用于静态/近静态相机片段，第三视角、移动相机、长镜头场景被排除在外；论文在结论中仅把它放入未来工作，说明当前适用范围仍有明显边界。
- **缺少数量的消融研究**：躯干标准化、不同损失权重 λ、正样本数、编码器结构等均未逐一验证，无法定量回答“哪个设计最重要”。
- **仿真到真实（sim2real）鸿沟**：

- **仿真到真实（sim2real）鸿沟**：所有策略评估均在 VTDexManip 仿真环境内完成，未部署到真实机械臂/灵巧手平台。真实场景中的手部感知噪声、物体物理特性差异、动态干扰、执行器延迟等因素均未被验证，因此检索质量优势能否在真实操作中转化为稳定的策略收益，目前仍属推断而非实证。
- **与前沿 VLA / 大模型方法的对比缺失**：实验对比对象以传统检索方法（Flow、HAND、STRAP）与单一 PPO 预训练基线（VT-JointPretrain）为主，未与当前主流的 VLA 微调、SiMDex 等大规模视觉-语言-动作后训练方法同台比较。

### 9. 改进建议与未来方向

1. **补齐消融实验**：至少应量化“躯干坐标系标准化”“DTW 排序损失”“集合损失”“边界负样本构造”四项设计逐一移除后的性能变化，以明确各模块的贡献比例。
2. **故障环节与误差传播分析**：针对 WiLoR → MoGe-2 → HaWoR → 躯干估计的级联流程，逐段注入噪声或替换模型，报告对检索指标的敏感性，以判断整个引擎的鲁棒性瓶颈。
3. **引入独立于 DTW 的评测真值**：可考虑用人工标注的“操作类型一致性”或基于物体状态变化的因果标签作为外部标准，打破“训练与评测同源”的循环论证局限。
4. **扩展可支持场景类型**：逐步支持移动相机、第三人称自由视角和更长范围的动作序列；可将现有“过滤掉移动相机片段”的限制放宽为“先行估计相机运动并补偿”。
5. **真实硬件部署验证**：将检索所得演示用于真实灵巧手平台的模仿学习或强化学习初始化，完善 sim2real 闭环验证。
6. **结合物体/场景语义**：在手部轨迹之外引入轻量的物体状态特征（如接触点、物体位姿变化），在不牺牲索引成本的前提下进一步提升“同一操作目标”的检索精度。

### 10. 总体评价与可复现性提示

- 本研究在问题定义、表征设计和评测控制上均有较高水准，提出的“以人手运动为媒介、以躯干坐标系为基准”的检索范式，为机器人利用互联网人类演示提供了新的可行路线；实验设计体现了较强的控制变量意识，结果也能支撑“检索质量可转化为策略收益”的核心论点。
- 不足之处集中在消融不充分、仿真局限和与前沿基线对比不足上；若作者能公开代码、模型权重与已构建的 100k 索引片段集合，并在补充材料中提供更细粒度的模块消融与失败案例分析，该工作对社区的复现价值和借鉴意义将显著提升。
