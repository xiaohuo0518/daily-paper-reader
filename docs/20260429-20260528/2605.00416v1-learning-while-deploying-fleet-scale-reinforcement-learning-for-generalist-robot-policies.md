## 摘要
通用机器人策略日益受益于大规模预训练，但仅靠离线数据不足以实现稳健的实世界部署。已部署的机器人会遇到分布偏移、长尾故障、任务变化以及人类纠正机会，而这些是固定演示数据集无法完全捕捉的。我们提出边部署边学习（LWD），一种面向通用视觉-语言-动作（VLA）策略的车队规模离线到在线强化学习持续后训练框架。从预训练的VLA策略开始，LWD通过利用整个机器人车队收集的自主轨迹和人类干预，在部署、共享物理经验、策略改进和重新部署之间形成闭环。为了从异质性、稀疏奖励的车队数据中稳定学习，LWD结合了分布隐式值学习（DIVL）用于鲁棒值估计，以及通过伴随匹配的Q学习（QAM）用于基于流的VLA动作生成器中的策略提取。我们在由16个双臂机器人组成的车队上，跨越八个真实世界操作任务（包括语义杂货补货和3-5分钟的长时域任务）验证了LWD。单个通用策略随着车队经验的积累而改进，平均成功率达到95%，在长时域任务上增益最大。

## Abstract
Generalist robot policies increasingly benefit from large-scale pretraining, but offline data alone is insufficient for robust real-world deployment. Deployed robots encounter distribution shifts, long-tail failures, task variations, and human correction opportunities that fixed demonstration datasets cannot fully capture. We present Learning While Deploying (LWD), a fleet-scale offline-to-online reinforcement learning framework for continual post-training of generalist Vision-Language-Action (VLA) policies. Starting from a pretrained VLA policy, LWD closes the loop between deployment, shared physical experience, policy improvement, and redeployment by using autonomous rollouts and human interventions collected across a robot fleet. To stabilize learning from heterogeneous, sparse-reward fleet data, LWD combines Distributional Implicit Value Learning (DIVL) for robust value estimation with Q-learning via Adjoint Matching (QAM) for policy extraction in flow-based VLA action generators. We validate LWD on a fleet of 16 dual-arm robots across eight real-world manipulation tasks, including semantic grocery restocking and 3--5 minute long-horizon tasks. A single generalist policy improves as fleet experience accumulates, reaching an average success rate of 95%, with the largest gains on long-horizon tasks.

- **研究背景**：现有方法要么只能处理小规模、短时域、单任务场景，要么将通用策略微调为专用策略，要么无法有效利用离线/离策略大数据。缺乏一种能够兼容预训练VLA、从大规模异质离线与在线数据中学习、并快速适应新部署数据的可扩展强化学习方法。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想：离线到在线强化学习的闭环数据飞轮

- 将部署视为持续改进的来源而非训练的终点。从离线预训练的VLA策略开始，通过机器人车队自主收集交互数据（包括人类干预），混合离线与在线经验更新策略，再将改进后的策略重新部署，形成闭环飞轮。
- 使用统一的强化学习目标贯穿离线预训练和在线微调两阶段，避免离线-在线目标不一致带来的训练不稳定问题。

### 关键技术细节

#### （1）分布隐式值学习（DIVL）
- **动机**：车队数据包含异质、多模态的回报分布（同一个状态-动作对的回报可能多峰、重尾）。标量值函数会模糊高回报模态，而分布值模型能保留这些模式。
- **方法**：
  - 学习一个状态条件化的值分布 \(p_\psi(v|s)\)（通过分类离散化实现，如201个原子，范围[-0.1, 1.1]），拟合目标Q值的分布。
  - 使用该分布的 \(\tau\)-分位数作为TD目标：\(y_Q = r_t + \gamma^H \text{Quant}_\tau(V_\psi(s_{t+H}))\)。
  - 分位数 \(\tau\) 根据分布熵自适应调整：\( \tau(s) = \text{clip}(\tau_{\text{base}} - \alpha H(s), \tau_{\min}, \tau_{\max}) \)，高不确定性时更保守，低不确定性时更乐观。
- **理论支撑**：文中证明了在理想情况下，直接使用不对称损失（如IQL的期望回归）与先拟合分布再提取相应分位数的两步骤方法等价，但分布表示更适合多模态数据。

#### （2）伴随匹配Q学习（QAM）
- **动机**：流匹配VLA策略通过多步去噪生成动作，直接通过值函数梯度反向传播到整个生成过程不稳定且计算昂贵。
- **方法**：
  - 定义KL正则化的策略改进目标：\(\pi^*(a|s) \propto \pi_\beta(a|s) \exp(Q_\phi(s,a)/\lambda)\)。
  - 将轨迹级优化转化为沿参考流路径的局部回归目标：
    \[
    L_{\text{QAM}}(\theta) = \mathbb{E}\left[ \int_0^1 \left\| \frac{f_\delta(s, a_w, w)}{\sigma_w} + \sigma_w \tilde{g}_w \right\|^2 dw \right],
    \]
    其中 \(\tilde{g}_1 = -\nabla_a Q_\phi(s, a_1)/\lambda\) 是从Critic提供的动作梯度出发的伴随状态终端条件。
  - 参考流 \(f_\beta\) 固定为行为克隆初始化的策略，优化的流 \(f_\theta\) 则在离线与在线阶段持续更新。

#### （3）离线到在线训练流程
- **离线阶段**：在静态离线缓冲区（包含演示、历史策略轨迹、人类引导探索数据）上预训练策略、Critic和值模型，使用n步TD目标（长时任务n=10，短任务n=1）。
- **在线阶段**：将离线初始化的策略部署到机器人车队，自主收集轨迹并允许人类干预，混合离线与在线缓冲区进行更新，每50个训练步同步一次策略到车队。在线阶段使用1步TD目标。
- **架构**：策略（π0.5流模型，含PaliGemma骨干和Gemma-300M动作专家）与值/Critic网络（共享Gemma3-SigLIP VLM骨干，独立输出头）分离。在线QAM更新时冻结策略的VLM骨干，只更新动作专家；值/Critic网络则完全微调。

## 6. 论文的主要结论与发现

1. **LWD（在线）在所有任务上取得最优平均成功率0.95**，显著优于SFT（0.76）、RECAP（0.85）、HG-DAgger（0.85）和LWD离线（0.88）。
